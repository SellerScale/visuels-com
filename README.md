# Visuels SellerScale

Images publiques pour les mails et les réseaux. Chaque lien ci-dessous s'affiche directement dans un mail.

## Extension Chrome 3.0 (octobre 2026)

Pour le mail : les `.jpg` (légers, 50 à 90 Ko, 1200×675). Les `.png` sont les mêmes en qualité maximale.
